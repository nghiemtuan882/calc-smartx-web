15 funciones, en movimiento

Cada animación está grabada en la propia app, en el idioma que estás leyendo.

01

Cálculos enlazados

  • Cambia un número y todo se actualiza

    Toca cualquier número para editarlo. Los resultados relacionados se recalculan.

  • Sigue desde un resultado

    Toca un resultado y luego + − × ÷. La nueva línea queda vinculada.

  • Arrastra para vincular

    Mantén y arrastra un número: aparece una tarjeta sobre tu dedo. Suéltala sobre un número para reemplazarlo, o bajo la última línea para crear otra.

  • Toca un número para vincularlo

    Tras pulsar un operador, toca cualquier número de arriba y entra ya vinculado.

  • Toca un signo para cambiarlo

    Toca + − × ÷ en una operación y elige otro signo. El resultado se recalcula al instante.

02

Escribir y corregir rápido

  • ⌫ inteligente

    Toca ⌫ para borrar carácter a carácter, signos incluidos. Con un resultado seleccionado, ⌫ salta al último número. Mantén ⌫ para borrar la línea entera.

  • Tecla 000 para importes rápidos

    Escribe 12 y toca 000 dos veces para obtener 12.000.000, sin pulsar 0 seis veces.

  • Arrastra un operador para mover

    Mantén y arrastra + − × ÷ o = para mover todo el cálculo.

03

Notas y diseño

  • Notas en cada número

    Pulsa la tecla de nota y escribe “precio unitario”, “cantidad” encima del número.

  • Desliza la columna de operadores para hacer zoom

    Pon el dedo en la columna + − × ÷ y desliza hacia arriba para acercar, hacia abajo para alejar.

  • Desliza el teclado para ajustar el espaciado

    Desliza en horizontal por la fila superior para separar los números. Desliza en vertical por la columna izquierda para separar las líneas.

  • A tu gusto

    Cambia el color, la fuente, el tamaño, el idioma, el modo oscuro y el teclado para zurdos.

04

Capturar y compartir

  • Capturas limpias

    Captura la pantalla completa, una zona dibujada o solo las líneas elegidas.

  • Captura solo las líneas que necesitas

    Elige líneas aunque estén separadas; la imagen las junta una tras otra.

  • Envía imágenes directo a tus chats

    Tras la captura, guarda la imagen o envíala al momento por Zalo, WhatsApp, Viber, Telegram o Messenger.
